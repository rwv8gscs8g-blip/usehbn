# HBN Local Runtime Tree

Esta pasta contem a memoria local do HBN para este projeto.

- `manifest.json`: identidade do protocolo e do alvo.
- `state.json`: estado estrutural local.
- `relay/`: coordenacao ativa entre humano e IAs.
- `relay-archive/`: iteracoes resolvidas ou encerradas.
- `knowledge/`: descobertas reutilizaveis.
- `reports/`: saidas resumidas e legiveis por humanos.
- `attention.json`: preferencia local de atencao humana para bloqueios e decisoes.
- `readbacks/`: registros formais de readback.
- `results/`: registros ERP.
- `connectors/`: aprovacoes locais, bridges geradas, requests anonimizados e registro do tradutor universal.

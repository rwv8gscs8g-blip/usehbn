# scratch/

Area temporaria e efemera para trabalho local.

- Sem segredos, tokens, credenciais, dados pessoais ou PII.
- Nada dentro de `scratch/` deve ser commitado, exceto este `README.md`.
- Symlinks em `scratch/` que apontem para fora de `scratch/` sao proibidos.
- Para fixtures efemeras de testes, use stage + reset conforme a knowledge 0023.

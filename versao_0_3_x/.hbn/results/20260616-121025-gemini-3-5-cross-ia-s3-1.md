- **Análise do Git Lock**: O erro de `rc 0->1` relatado pelo orquestrador no `git show :INDEX` sob sandbox é puramente ambiental. ## Seção DESIGN-AREA-TEMP (Parte B)

### Recomendação de Design: Área Temporária Segura para IAs

#### 1. Abordagem Mais Segura
A abordagem ideal para evitar poluição e riscos de segurança divide-se em duas regras complementares:

1. **Fora do Repositório (Regra Primária/Padrão)**:
   Os rascunhos efêmeros e fixtures que não requerem versionamento ou persistência compartilhada devem ser gerados no diretório temporário do sistema operacional (resolvido por `$TMPDIR` ou `/tmp`), ou no espaço específico do agente fora do workspace (por exemplo, `<appDataDir>/brain/<conversation-id>/scratch/`).
   
2. **Dentro do Repositório (Quando Inevitável devido a restrições de Cwd das ferramentas)**:
   Se for estritamente necessário que os arquivos temporários residam sob a árvore do projeto (por exemplo, para execução de ferramentas de teste locais que usam paths relativos estritos), eles devem residir em uma pasta exclusiva chamada `/scratch/` (na raiz do repositório).

#### 2. Vetores de Exposição Residual & Resolução
- **Vetor A: Exposição por bypass local (`git commit --no-verify` ou bypass de env)**.
  - *Mitigação*: O CI deve executar de forma não-bypassável o guard anti-stage no diff de push, falhando o build se qualquer path sob `/scratch/` estiver presente no commit diff.
- **Vetor B: Arquivo já sob controle de versão antes de ser ignorado**.
  - *Mitigação*: O guard anti-stage deve rodar a busca no diff staged geral, ignorando se está listado ou não em `.gitignore`.
- **Vetor C: Vazamento local por indexadores de busca ou backups do sistema**.
  - *Mitigação*: Adicionar regras de exclusão nos arquivos de configuração do repositório (ex: `.vscode/settings.json`, exclude patterns) e garantir que o ciclo de vida da IA limpe a pasta `/scratch/` ao final da execução.

#### 3. Proposta de Guard anti-stage sugerido (`guards/assert-scratch-isolated.sh`)
```bash
#!/usr/bin/env bash
# =============================================================================
# G-SCRATCH-LOCK: impede o commit de qualquer rascunho ou fixture sob /scratch/
# =============================================================================
set -euo pipefail

SCRATCH_DIR="scratch"
# Obtém arquivos stageados relativos à versão ativa
STAGED_FILES="$(git diff --cached --name-only 2>/dev/null || true)"

FAIL=0
for f in $STAGED_FILES; do
    if [[ "$f" == "${SCRATCH_DIR}/"* ]]; then
        echo "  [hbn-guards/scratch-lock] ✗ COMMIT BLOQUEADO: Artefato temporário no escopo de scratch stageado: ${f}" >&2
        FAIL=1
    fi
done

if [[ "$FAIL" -ne 0 ]]; then
    exit 1
fi
exit 0
```
- **Configuração de Gitignore**:
  Adicionar a linha `/scratch/` (com barra inicial para ancorar na raiz) no `.gitignore` do repositório.

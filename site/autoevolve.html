Autoevolve — vitrine pública dos ciclos

Cada Quarta de Sanitização, o HBN executa um ciclo de microdeltas auditáveis (ADR-010). Esta página renderiza os ciclos a partir de .hbn/autoevolve/cycle-*.jsonl.

Esta página é estática. Para gerar a tabela com os dados reais de um ciclo, rode hbn autoevolve audit --cycle <id> --output site/autoevolve-fragment.html e cole o conteúdo do fragmento no bloco abaixo.

Ciclo de exemplo — 2026-05-13

cycle 2026-05-13

# Braço Microdelta (slug) Status Testes Commit
Carregue um fragmento gerado por hbn autoevolve audit --output ... ou utilize JavaScript no cliente para hidratar a partir de um JSON exportado.

Como funciona em três frases

  1. Cada microdelta é uma alteração pequena (≤80 linhas de diff) com teste obrigatório.
  2. O ciclo aplica microdeltas em todos os 14 braços do sistema na janela 06–12h BRT.
  3. O resultado é selado em JSONL com 6 sinais HBN canônicos, incluindo AUTOEVOLVE_TICK.
